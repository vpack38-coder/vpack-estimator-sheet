📊 เทียบช่วงราคา — ดูเรทราคาหลายสเต็ป (งานแผ่น Digital)
กรอกแล้วกด “สร้างตาราง”
ตัวอย่าง: ต้องการดูราคา 50 ถึง 100,000 ดวง โดยเพิ่มทีละ 5,000 ดวง → เลือก “เพิ่มทีละ 5,000” แล้วกด “สร้างตารางเทียบราคา”
ต้องการจำนวนไม่ตามสเต็ป → เลือก “คีย์จำนวนเอง” แล้วพิมพ์ เช่น 50,500,1000,5000,10000
ขั้นต่ำของช่วงนี้กำหนดได้ตั้งแต่ 50 ดวงขึ้นไป (ตามยอดสั่งขั้นต่ำของงานแผ่น Digital)
🎯 อยากได้ช่วงราคาแบบเสนอลูกค้าจริง (เช่น 20-100 ดวง / 101-300 ดวง) → เลือก “ใช้ช่วงจากตารางราคาขั้นบันได” ระบบจะดึงช่วงจากตารางขั้นบันไดที่ตั้งไว้ด้านบนให้เลย ไม่ต้องคีย์ซ้ำ
🎯 กำลังใช้ช่วงจากตารางราคาขั้นบันได — ถ้าอยากแก้ช่วง/ราคา ให้ไปแก้ที่ “ตารางราคาขั้นบันได” ในโหมดราคาด้านบน (ช่องกรอกราคาหลักของงาน) ตารางนี้จะอัปเดตตามอัตโนมัติ
ช่วงจำนวนสั่งแผ่นจริงต้นทุน/ดวงราคาต่อดวงยอดก่อน VATกำไร
ตารางนี้ใช้ต้นทุนและค่าต่าง ๆ ของงานปัจจุบันในการคำนวณเทียบราคา และ ไม่เปลี่ยนราคาหลัก ของงานด้านบนโดยอัตโนมัติ

📋 ประวัติการคำนวณ & ต้นทุนย้อนหลัง (Saved History & Templates)

วันที่/เวลา ประเภท ชื่องาน / ลูกค้า รหัสกระดาษ ขนาดชิ้นงาน จำนวนสั่ง ยอดสุทธิ กำไร สถานะเอกสาร จัดการ / โหลดเป็นต้นแบบ
ยังไม่มีประวัติที่บันทึกไว้
⚙️ วิธีตั้งค่าเชื่อมต่อ Google Sheets (ให้ทีมเห็นประวัติร่วมกัน + ซิงค์ข้อมูลกลับได้)
  1. เปิด Google Sheets ไฟล์ที่ใช้เก็บประวัติอยู่แล้ว (หรือสร้างใหม่ก็ได้ถ้ายังไม่เคยตั้งค่า)
  2. เมนู Extensions > Apps Script — ถ้ามีโค้ดอยู่แล้วและใช้งานได้ปกติ ไม่ต้องแก้ไขอะไรเพิ่ม ระบบซิงค์รองรับได้ทั้งแบบที่ doGet ส่งผลลัพธ์กลับเป็น array ตรงๆ และแบบที่ห่อด้วย {ok, records} ถ้ายังไม่เคยตั้งค่าเลย ให้วางโค้ดจากไฟล์ vpack-sheets-webhook.gs.txt ที่ให้ไว้ได้ (เป็นตัวอย่างโครงสร้างพื้นฐาน)
  3. กด Deploy > New deployment เลือกประเภท Web app, Execute as Me, Who has access Anyone (ถ้าแก้โค้ดเดิมที่ deploy อยู่แล้ว ให้ใช้ Manage deployments > แก้ไข > New version แทน จะได้ URL เดิม)
  4. คัดลอก Web app URL ที่ได้ มาวางในช่อง "Google Sheets Webhook URL" ด้านบนสุดของหน้านี้ แล้วกด "บันทึกประวัติ" หรือคลิกช่องอื่นให้ระบบบันทึก URL ไว้
  5. กด "ทดสอบเชื่อมต่อ" แล้วเช็คใน Sheet ว่ามีแถวทดสอบขึ้นมาไหม
  6. เมื่อต้องการดึงประวัติที่เคยบันทึกไว้ใน Sheet กลับเข้ามาในเครื่อง (เช่น เปิดจากเครื่องใหม่ หรือล้างประวัติในเบราว์เซอร์ไปแล้ว) ให้กดปุ่ม "🔄 ซิงค์ประวัติจาก Google Sheets" ด้านบนของตารางประวัติ
หลังตั้งค่าแล้ว ทุกครั้งที่กด "บันทึกประวัติ" ระบบจะส่งรายละเอียดงานแบบเต็ม (รวมพารามิเตอร์ทุกค่า) ไปที่ Sheet โดยอัตโนมัติ และเมื่อเปลี่ยนสถานะเอกสารในตารางด้านบน สถานะใน Sheet จะอัปเดตตามให้ด้วย ส่วนปุ่ม "ซิงค์ประวัติจาก Google Sheets" จะดึงทุกแถวจาก Sheet กลับมารวมกับประวัติในเครื่อง — รายการที่มีรหัสเดียวกันจะถูกอัปเดตให้ตรงกับใน Sheet ส่วนรายการที่ไม่เคยมีในเครื่องจะถูกเพิ่มเข้ามาใหม่ (จะไม่ลบรายการที่มีอยู่ในเครื่องออก) — ⚠️ หากมี Apps Script ใช้งานอยู่แล้ว อย่านำไฟล์ตัวอย่าง vpack-sheets-webhook.gs.txt ไปวางทับ เพราะชื่อชีตและลำดับคอลัมน์อาจไม่ตรงกับของเดิม ทำให้ข้อมูลเก่าเพี้ยนได้
